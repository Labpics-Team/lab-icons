# Анатомия иконок — справка

[Сетка](../semantics/grid.json) задаёт параметры геометрии,
[декларации](../semantics/anatomy.json) — конструкцию вариантов.
Для объявленной генерируемой формы редактируется декларация с последующей
перегенерацией, а не вручную скопированный SVG path.

## Единицы

| Величина | Единица |
|---|---|
| Длины, координаты и радиусы декларации | Доли канвы; перевод в координаты выполняет генератор |
| Углы | Градусы |
| Число частей, зубьев или спиц | Целое количество |
| Сглаживание и прочие коэффициенты формы | Безразмерные величины |

Значения и допустимые диапазоны читайте из `semantics/grid.json`.
Вложенность в `ratios` не делает углы или коэффициент сглаживания длиной.

## Назначение параметров сетки

| Поле внутри `ratios` | Назначение |
|---|---|
| `strokeWidth.base` | Базовый штрих Outline |
| `strokeWidth.bold` | Отдельный вес штриховых Filled-форм |
| `strokeWidth.containerGlyph` | Штрих глифа внутри контейнера |
| `strokeWidth.enclosureRing` | Вес кольца-обрамления |
| `strokeWidth.capRadius` | Радиус окончания штриха |
| `cornerSmoothing` | Профиль объявленных скруглений; не постобработка всех углов |
| `keylines` | Размеры кругового, квадратного, широкого и высокого семейств |
| `clearanceMin` | Минимальный охранный зазор |
| `tolerances` | Допуски соответствующих геометрических проверок |

Базовый и жирный веса — независимые выбранные параметры. Их отношение не
объявляется универсальным законом. Размеры keyline-семейств также являются
продуктовым решением, а не типографским overshoot.

## Архетипы

`radial-gear` описывает радиальную зубчатую форму; `arc-terminal` — дугу с
терминалом; `stroke-v` — шеврон; `container-glyph` — глиф с обрамлением;
`rounded-rect-container` — скруглённую рамку; `composite` — композицию частей.
Текущий набор конструкций и их параметры определяют декларации и
[генератор](../src/core/anatomy-gen.js), а не исчерпывающий ручной каталог здесь.

## Пара Outline и Filled

Для одноконтейнерной формы силуэт Filled соответствует внешнему контуру
Outline. У штриховой формы Filled является самостоятельным более тяжёлым
начертанием с сохранением осевых длин. Изменение веса должно сохранять
оговорённые габариты и отрицательное пространство; механическое расширение
произвольного Outline не заменяет авторский Filled-мастер.

Проверки регистрации пары и качества используют значения из машинных
политик. Результат диагностического режима не означает прохождение жёсткой
приёмки. [Жизненный цикл](lifecycle.md) объясняет эту границу.

## Работа с декларациями

Для изменения корпуса используйте [процедуру приёма](agent-workflow.md).
Обновление каталога и производных артефактов выполняется через `pnpm build`,
после чего обязателен `pnpm verify`.

Внутренний `buildGlyph()` не является публичной точкой входа npm-пакета.
Потребитель получает геометрию через `@labpics/icons/ir` и проверяет возможности
варианта через `glyphCapabilities()`.
