# Каталог символов

Каталог показывает весь авторский корпус. Поиск работает по имени; фильтры
выделяют символы с движением и связанными состояниями. Справа находятся
размер, вес, оптика, цвет, дата и управление воспроизведением.
На узком экране настройка открывается отдельной панелью; Escape возвращает
к выбранной плитке. `/` переводит фокус в поиск.

SVG сохраняет текущую видимую позу и цвет. Lottie и dotLottie сохраняют выбранный
жест или переход; Kotlin содержит полный `SymbolData` для Compose. Копирование
даёт код с публичными imports, свойствами и цветом. Ссылка сохраняет символ,
начертание и группу состояний.

## Сборка и размещение

```sh
pnpm build
pnpm catalog:build
pnpm catalog:check
```

Результат — самостоятельный статический каталог `preview/catalog/`.
Его можно разместить в корне сайта или в каталоге `/icons/`; все ресурсы имеют
относительные адреса. Для интеграции укажите отдельный каталог назначения:

```sh
node scripts/build-icon-catalog.mjs --out-dir <site-output>/icons
```

Сборщик не требует LabUI и не добавляет website в npm-пакет Icons.
CI сохраняет каталог отдельным artifact. Исходный `symbols/source.json`
задаёт список семейств, состояний и загрузчиков; ручного второго перечня нет.
Сетка использует ленивые SVG-изображения. Числовые модели и exporter загружаются
только при выборе символа или скачивании соответствующего формата.

`catalog:check` запускается без окна и звука. Проверяется настоящий шрифт
кириллицы, светлая/тёмная тема, мобильная навигация, прерывание загрузки,
скопированный исполняемый код, движение и скачивание всех четырёх форматов.
PNG и receipt записываются в `preview/catalog-check/`.

Опора интерфейса — [каталог Lucide](https://lucide.dev/icons/): сетка символов
и расположенные рядом настройки. Рисунок, оси и движение принадлежат Lab Icons.
