# Проверка negative Draw

На 2026-11-17 независимое ревью приняло `5ab873b` после исправления возврата
частично нарисованной Filled-галочки в selected. Сценарий
`selected → draw(.25) → unselected(.5) → selected` сохраняет видимую позу:
`stroke-dashoffset .75 → .375 → 0`; итоговый растр совпадает с полной галочкой.

Проверяющая самостоятельно выполнила headless Web-проверку корпуса (660
вариантов, 0 часов у неподвижных mounts), 54 сравнения negative на оптических
опорах и разных фонах, а также 13 native-тестов через JUnitCore с
`java.awt.headless=true`. Видимых окон и звука не было. После disposal `live=0`.
Mask сохраняет прозрачный фон; округление полупрозрачного цвета до канала
может отличаться от compound SVG и не ограничивается только AA-границей.

Полный `pnpm verify` после обновления фактических размеров прошёл: 190 test
files, 2790 tests PASS, 27 skipped. Включены проверка упаковки, установленные
consumers, exports, размеры и исключение чужих модулей из узких входов.

## Стоимость представления

Прежняя проба дублировала все оптические коэффициенты в `semantics.paths`,
увеличивая checkmark-circle с 37190 до 54509 B. Эта копия удалена:
`pathIndex + contourIndices` ссылаются на исходные числовые данные. Native
части разделяют sampled buffer; SVG parsing и boolean-операции в runtime
не появились.
