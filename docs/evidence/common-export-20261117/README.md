# Общий экспорт · различающий опыт

17 ноября 2026, после web calendar `899118c`. Это эксперимент устройства
Lottie-экспорта; публичный exporter ещё использует прежний source target.

Исходный вопрос EXPORT-01: сможет ли тот же числовой символ сохранить
оптические оси, открытые штрихи, вращение отдельных отрицательных частей и draw
в настоящем Lottie player, без нового набора геометрии и runtime SVG parser?

Опыт использует `IconSymbol`, общий sampler и selectors частей. M/L/C/Z
переводятся в вершины и относительные cubic tangents без аппроксимации.
Positive части рисуются белым, negative — чёрным внутри precomposition.
Полученное покрытие служит luma matte единственного слоя цвета. Draw
дополнительно применяет alpha matte из штриха направляющей с trim-path;
направляющая разбирается offline. Повороты используют числовые source-pivots.

`lottie-web` 5.13.0, SVG renderer, headless Chrome; размер растра 96 px,
цвет alpha .37. [Квитанция](player-receipt.json) содержит 234 сравнения с
публичным mounted Motion: calendar-number (18 статических), time (108 поз
advance 0…2 h), checkmark-circle (108 поз draw). Каждая группа включает оба
начертания и девять опор weight/opsz. Для Motion выбирается явная конечная поза;
player получает настоящие rotation/trim keyframes и seek нужного кадра.

Максимальное среднее alpha-расхождение — 0.005859375 уровня на пиксель;
максимальное расхождение одного пикселя — 12, максимальный alpha — 94.
Слои не переокрашивают пересечения полупрозрачным цветом. Большинство поз
совпадает точно; причина оставшихся небольших расхождений отдельно не доказана.

Первое сравнение time/Filled с исходным compound SVG давало среднее 0.4362:
растеризация общего исходного контура и уже принятой проекции отдельных
частей различается. Отдельный опыт против общего mounted пути снизил это
до 0.00098. При выпуске понадобятся оба сравнения: соответствие общему
исполнителю и сохранение авторского рисунка в пределах принятой растеризации.

Повторить: после `pnpm build:ir` выполнить
`node docs/evidence/common-export-20261117/probe.mjs`.
Он не меняет production-код и сохраняет свежие данные в
`preview/lottie-common-probe.json`; все player уничтожаются, Chrome закрывается.

Опыт не проверял все 660 вариантов, transition разных состояний/дат,
path-keyframes, canvas padding, installed exporter, dotLottie или другие players.
Указанные ограничения остаются работой общего экспорта; небольшой raster diff
сам по себе не означает готовности к выпуску.

Источники: [слои и matte](https://lottie.github.io/lottie-spec/1.0/specs/layers/),
[режимы matte/trim](https://lottie.github.io/lottie-spec/1.0/specs/constants/),
[штрихи и группы](https://lottie.github.io/lottie-spec/1.0/specs/shapes/).

## Уточнение независимого ревью

Ревью подтвердило 234 позы, но расширение опыта на database-search/Outline
показало неверное допущение прототипа: глобальная маска объединяет независимые
paints. Максимальный alpha прототипа 94 вместо 153 в web; средняя alpha-разница
1.10449. При реализации покрытие объединяется **только по явному `part.layer`**;
части без него сохраняют отдельные paints и исходный порядок. Текущий probe
сохраняет ограниченный опыт, его общий слой нельзя переносить на весь корпус.

Принятое направление EXPORT-01: прямое lowering IconSymbol, числовых частей и
semantic tracks; общие pose/transition samplers с runtime. Отдельное развитие
GlyphIR не требуется. dotLottie упаковывает тот же полученный Lottie JSON.

## Установленный общий exporter · 17 ноября 2026

`@labpics/icons/lottie` теперь экспортирует числовой `IconSymbol` напрямую.
`/lottie/<id>` — тонкая совместимая обёртка над тем же exporter. Runtime
`dist/ir/lottie-runtime.js` и его типы исключены из release contract;
offline author compiler остаётся для старых author API и проверок источника.
Отдельные Lottie-геометрии больше не генерируются и не поставляются.

Общие pose и motion samplers обеспечивают static, weight/opsz, дату, состояние,
semantic gesture, reverse/partial, elapsed-hours и переходы соответствующих
путей. Web `set()` интерполирует совместимую оптику; прерывание продолжает
последнюю видимую геометрию. Первый кадр по-прежнему записывается синхронно до
создания часов Motion. Draw guide хранится числовым путём, его SVG-разбор
выполняется только offline. Fractional terminal frame сохраняет запрошенную
длительность; следующий кадр оставляет конечную позу доступной для seek.

`node scripts/check-package-artifact.js --browser` собрал чистый source copy,
упаковал и установил tarball в отдельный consumer. ESM, декларации и attw
прошли; на 2026-11-17 получены 1508 файлов, включая 1505 release artifacts и npm metadata.

Первые два опыта используют `lottie-web@5.13.0`, SVG renderer, headless Chrome,
96 px и цвет с alpha .37. Динамика включает оба начертания, девять опор,
межкадровые позиции, calendar date/state, volume state, optical transition,
clock, rotation и positive/negative draw. Проверка dotLottie использует настоящий
WASM player, явно заданные кадры и подтверждает изменение рисунка во времени.
Она доказывает эквивалентность архива JSON в одном player, а не совпадение
растеризации ThorVG и браузерного SVG.

### Причины двух исправлений

Opacity слоя должна применяться после coverage matte. Alpha цвета внутри
маски иначе округляется раньше: переход calendar с общей opacity .75 давал
71 вместо 70. Exporter сначала вычисляет coverage, затем matte+tint и только
после этого общую opacity. Calendar-state после исправления имеет худшее
среднее расхождение 0.0028212 в 126 сравнениях.

SVG `L` и эквивалентный cubic имеют одинаковый след, но разные параметры
кривой и растеризацию. Опыт с handles на 1/3 и 2/3 устранил расхождение volume,
но ухудшил 23 других формы полного корпуса: худшее среднее стало 0.280599.
В отдельной части video-camera-off линия и cubic с нулевыми handles совпали
точно; handles 1/3 дали 0.07704. Поэтому оставлены стандартные нулевые handles,
без исключений по именам иконок. Полный финальный корпус проверен заново.
Это измеренная граница сглаживания, а не изменение принятой оптики.
Assertions ограничивают среднее до .05 для корпуса и .125 для динамики,
один пиксель до 32 уровней и максимум alpha до одного уровня.

Каждый path-keyframe получает независимые объекты `e` и следующего `s`:
lottie-web переводит относительные tangents в абсолютные на месте, поэтому
shared object проходил преобразование дважды. Проверка identity и настоящий
player защищают от этой ошибки.

### Стоимость и пределы checkpoint

[Квитанция размера](cost-receipt.json) сохраняет окружение, lockfile digest,
прежние правила удалённых артефактов и фактические изменения. Сумма exact
release files уменьшилась с 35 171 381 до 32 300 120 B; сумма gzip каждого
файла — с 11 022 650 до 10 054 235 B. Это не размер сжатого tarball.
Изменённым файлам заданы точные измеренные пределы; неизменённые бюджеты
сохранены. 330 прежних JS targets заменены тонкими wrappers.

Один статический импорт остался 1090 B / 553 B gzip. Сценарий time + общий
Lottie export — 52 785 / 20 118 B; с ZIP writer — 60 870 / 24 037 B.
Ни player, ни весь каталог туда не входят. Общий exporter — 39 655 / 14 626 B.
Render остаётся 8990 / 3277 B после принятого calendar checkpoint.
Motion — 32 917 / 11 683 B против 31 321 / 11 148 B на `0e551d2`:
добавилась совместимая интерполяция оптики. Прежний size ratchet ещё не
учитывал принятый calendar, поэтому его общий прирост нельзя приписывать
только exporter.

Точность adaptive scalar baking проверяется в выбранных кадрах; midpoint
tolerance .0001 не является доказанной верхней границей ошибки всей кривой.
Интерактивное прерывание проверяется в web runtime, не обещается в файле.
Legacy `variation` возвращает `VARIATION_UNSUPPORTED`; неизвестные endpoint
options отклоняются. Каталог, native-паритет новой optical interpolation,
независимое ревью и публикация 0.4.0 остаются дальнейшей работой.

Итоговая [квитанция проверок](verification.json): полный Vitest run прошёл
193 тестовых файла, 2735 проверок; 27 ранее отключённых проверок пропущены.
TypeScript, package/consumer size, export surface, publint, tree shaking и
docs drift прошли. Квитанция относится к этому checkpoint до commit, её
`baseSha` указывает родителя, а не выдаёт рабочее дерево за чистый commit.

Источники упаковки: [dotLottie 2.0](https://dotlottie.io/spec/2.0/),
[Node subpath patterns](https://nodejs.org/api/packages.html#subpath-patterns),
[lottie-web](https://github.com/airbnb/lottie-web). Private декларации лежат
