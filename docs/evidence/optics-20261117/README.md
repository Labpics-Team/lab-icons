# Срез для независимого оптического ревью

Все 330 семейств / 660 вариантов имеют совместимые опоры weight 300/400/600
и opsz 16/24/48 с точным исходным центром. [Независимое принятие](independent-review.md)
зафиксировано для геометрии `f6d2777`.

Повторная доводка охватывает 90 Filled-вариантов: 159 замкнутых смысловых контуров
и островков, 12 открытых участков. Plus/minus уже имеют отдельные авторские рецепты
отрицательных штрихов и в эти числа не входят. Разметка выполнена независимой
reviewer по всему исходному корпусу и атласу: структурные отверстия отделены
от самостоятельных отрицательных знаков, открытые участки имеют точные selectors.

Направление веса меняется до построения стыков. Согласование ближайших controls
сохраняет общие точки положительного и отрицательного продолжений. Пример Console:
толщина отрицательного подчёркивания при opsz24 меняется 1.51 → 1.80 → 2.18.
Две общие точки Share-display совпадают на всех девяти опорах и 16 промежуточных
положениях. Средняя опора сохраняет авторские coordinates без округления.

Прошли 37 оптических тестов. Полная геометрическая диагностика осталась на прежнем
уровне: 30 замечаний на опорах и 59 между ними у 12 вариантов. Все они относятся
к дополнительным пересечениям; winding-change, near-collapse и canvas-overflow
не обнаружены. Часть исходников уже содержит микроскопические пересечения.
Конечная сетка не доказывает корректность всей непрерывной области.

[Receipt](receipt.json) фиксирует точный digest compiled geometry каждого
семейства и SHA-256 всех 66 HTML/PNG атласа. Локальный атлас находится в
`preview/optical-atlas/index.html`, снимки — в `preview/optical-atlas/screenshots`.
На 2026-11-17 Chrome 157.0.8103.51 отрисовала 19 800 SVG без горизонтального переполнения.
Каталог preview исключён из Git; его можно воспроизвести:

```sh
node scripts/build-optical-atlas.mjs
node scripts/capture-optical-atlas.mjs --chrome
```

В commit 959f5f4 отдельно установленный preview tarball прошёл 16 500 рендеров
всего корпуса, проверку NodeNext TypeScript и Chrome consumer. Один bundle содержит
только plus-circle и renderer; именованный static import занимает 1096 bytes.
[Снимок consumer](public-consumer.png) относится к этому предыдущему срезу:
геометрия plus-circle при семантической доводке не менялась. Production release,
native Motion, полный каталог и performance qualification ещё не завершены.
