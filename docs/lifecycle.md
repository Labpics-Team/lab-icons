# Жизненный цикл иконки

У модели независимо описаны представление геометрии, решение о приёмке и
доступные возможности. Например, авторский SVG может быть готов к поставке,
пока параметрическая модель ещё проходит проверку.

| Поле | Значение |
|---|---|
| `representation`: `source`, `transcript`, `semantic` | Способ представления геометрии |
| `acceptance`: `candidate`, `accepted`, `rejected` | Решение о приёмке конкретной модели |
| `capabilities` | Поддержанные оси, части и жесты |

Транскрипция точно переносит контур и служит анализу или миграции.
В основной публичный пакет она подключается явно. Поддержка смысловых частей,
осей и жестов определяется их собственными проверками.

## Условия перехода

Для приёмки модели проверяются геометрия и соответствие исходнику.
Для оси проверяются диапазон и растровые фазы; для жеста проверяются
траектория и топология. Готовность определяется по результатам этих проверок.

Пороги заданы в [политике качества](../semantics/quality-thresholds.json).
Меняйте их вместе с обоснованием и проверкой влияния на корпус.

## Хранение решений

Декларация содержит действующее состояние модели. Git сохраняет историю
изменений, а неизменяемые артефакты сохраняют результаты конкретных проверок.
Смена формата геометрии оставляет решение о приёмке и доступные возможности
отдельными полями.

## Добавление иконки

Первой поставкой может быть авторский SVG после проверок корпуса и визуальной
приёмки. Параметрическая модель добавляется отдельным изменением, когда готовы
её конструкция и проверки.

Порядок работы описан в [добавлении иконки](agent-workflow.md), значения
motion-состояний в [анатомической модели](anatomy-model.md#граница-возможностей).
