# Компактная сборка с сохранением публичного поведения

Паритетный разбор исходного запроса принадлежит одному закрытому
`author-request-runtime`. Оба авторских закона и обычный символ используют
его; `glyph()` по умолчанию возвращает заранее собранный объект без разбора
запроса и новых объектов.

Сборка сжимает пробелы и сохраняет идентификаторы. `minifySyntax` в esbuild
0.28.1 удалял имена возвращаемых `glyph` и `glyphCapabilities`: настоящий
native consumer обнаружил пустые `function.name`. Отдельный опыт дал
725/335 B raw/gzip с этим дефектом, 758/340 B при сжатии пробелов и
1027/434 B с `keepNames`. Выбран вариант без дополнительных `__name`-вызовов.
Эти три числа относятся к symbol-runtime без provenance-заголовка.

[Официальная API](https://esbuild.github.io/api/#minify) разделяет три
настройки minification; [keepNames](https://esbuild.github.io/api/#keep-names)
восстанавливает наблюдаемые имена. Отдельный
[контрпример](https://github.com/evanw/esbuild/issues/3965) показывает цену
добавленных name-операций для tree shaking. Имена проверяются после emit;
настройка сама по себе не удостоверяет результат.

Production helper выполнил семь узких bundle-проекций на Windows x64,
Node 24.15.0, esbuild 0.28.1; gzip — fflate 0.8.3, level 9, mtime 0.
Все пять ранее ограниченных крупных модулей остались ниже прежних потолков:

| Артефакт | Кандидат raw/gzip, B | Прежний потолок raw/gzip, B |
| --- | ---: | ---: |
| compiler | 120591/37074 | 154789/42120 |
| recipes | 52468/13389 | 65216/15356 |
| authoring | 56638/17677 | 70596/19660 |
| motion | 13381/3715 | 14620/3817 |
| Lottie runtime | 9467/3463 | 11590/3776 |

Три точных entry из `consumer-size-ratchet.json` также соблюдают неизменённые
потолки: `alert` — 11182/3158 B, `time` — 11403/3142 B, статический `time` —
1155/583 B. Их bundle исполняется; обе независимые авторские формы совпадают
с контролем. Семь compiled-consumer tests и 53 проверки fixtures/fidelity
прошли. Literal-only consumer удаляет admission и metadata; снятие PURE
аннотаций сохраняло SVG, но удерживало runtime и вызывало точный отказ теста.

Сравнение runtime политик использует baseline
`3d59683295adf903a6aea32aafd36b0caa331526` с теми же текущими payload/emitter.
Это не пересборка всего прежнего пакета. При таком контроле исправленная
семантика запроса стоит дополнительно 62 raw и 50/49 gzip B для `alert`/`time`.
Native closure `plus-circle` содержит новый import hop: 15870 raw B и
4456 B суммы отдельно сжатых модулей против 15964/4309 B контроля.
Уменьшение raw в этом сценарии сопровождается увеличением этой суммы gzip.

Это измерение байтов production-проекции. Полная пакетная сборка, registry
install, браузер, timing и memory stress в данном опыте не выполнялись.
Результаты и source digests сохраняются рядом в JSON; удалённая проверка
реального пакета остаётся отдельной границей приёмки.
