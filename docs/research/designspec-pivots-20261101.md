# Семантический центр части

**Diátaxis:** explanation. Проверено 2026-11-01.

Публичная DesignSpec уже строит именованные якоря и сохраняет их в результате.
До этого среза часть получала только центр bounding box: связь с основанием
руки или центром неполной дуги терялась на границе GlyphIR. Рука от
`(0.5, 0.5)` до `(0.5, 0.3)` получала pivot `(0.5, 0.4)`; её вращение
перемещало основание. Обе позиции допустимы геометрически, но выражают
разный смысл движения.

[CSS Transforms Level 1 §6](https://www.w3.org/TR/css-transforms-1/#transform-box)
определяет reference box отдельно от transform origin. SVG view-box задаёт
систему координат; bounding box части не определяет семантический pivot.
[SVG2 coordinate systems](https://www.w3.org/TR/SVG2/coords.html) сохраняет
это различие. Эти источники задают координатную границу, а не способ угадать
опору по форме.

Варианты: автоматически использовать `geometry.from` для всех линий;
определять pivot по роли; передавать произвольный transform; явно связать
part с имеющимся DesignAnchor. Первые два случая не различают руку,
симметричную планку и перемычку; transform создаёт обход семантической
грамматики. Принята ссылка `part.anchor`: одна существующая модель якорей,
проверенная ссылка и текущий `GlyphPart.anchorSource: 'declared'`.

Source controls используют line, capsule и неполную arc: явный pivot
сохраняется при lowering и compile, контур/SVG/topology остаются прежними,
digest спецификации меняется. Без ссылки сохраняется прежний bbox pivot.
Неизвестные id, raw координаты и null получают typed refusal. Контрпример
повторяется на 16/24/48 и двух variant labels; это не оптическая приёмка
независимых Figma начертаний.

Срез не меняет 660 Figma masters и не принимает новую `time.advance`:
её авторский compound hand/countershape по-прежнему требует доказанного
разделения. Исполнение и interruption принадлежат Lab Motion; эта грамматика
передаёт ему сохранённую семантику части.
