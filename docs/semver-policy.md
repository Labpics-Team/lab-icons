# Semver-политика публичных поверхностей

Роль: справка (точный контракт классификации изменений; r2 DOC-01).

Пакет: `@labpics/icons`. Поверхности: `.` (статические SVG-экспорты),
`./ir` (Glyph IR), `./ir/recipes`. Опубликовано в npm: 0.2.0; текущий
мажор 0.x — минор может ломать (semver §4), но политика ниже действует
как обещание с момента первого production-потребителя.

## Классификация изменений

| Изменение | До первого потребителя | После |
|---|---|---|
| Новое имя иконки (экспорт + catalog) | minor | minor |
| Удаление/переименование имени | minor + deprecation-запись | major |
| Байтовое изменение shipped SVG (тот же смысл) | patch | patch |
| Смена формы знака (смысл/узнаваемость) | minor | major |
| Новая ось у варианта (supportedAxes растёт) | minor | minor |
| Удаление оси у варианта | minor | major |
| Расширение union-типа (`MotionCapabilityState`, `track.kind`, `PartRole`, `IconVariant`) | minor | **major** (exhaustive-switch потребителя ломается) |
| Новый необязательный ключ объекта контракта | minor | minor |
| Изменение семантики существующего ключа | запрещено | запрещено (новое имя ключа) |
| `topologySignature`: формат строки | opaque-контракт: сравнение только на равенство; смена формата | patch |
| Пороги `quality-thresholds.json` | minor (числа — контракт качества, не API) | minor |
| Gesture: изменение траектории/easing существующего id | запрещено | запрещено (новый id) |
| `proposalVersion`: новая версия формата | minor; старые версии принимаются или reject с кодом | тот же закон |

## Нестабильные поверхности (заявлены до стабилизации)

- **Motion/morph контракты** (`MotionGestureContract`, `sampleMotionGesture`,
  capability-состояния): нестабильны до MOTION-CONTRACT-01; расширение
  union'ов в 0.x допускается minor'ом, потребителю рекомендован
  non-exhaustive default-case. Стабилизация — отдельным minor с записью здесь.
- **`iconDesignContract.agent`** (repo-команды pnpm): исключается из
  публичного контракта при CONTRACT-01 — команды бессмысленны вне репо,
  Хайрам заморозит строки. До тех пор — нестабильная поверхность.

## Механика

- Совместимость соседних версий: потребитель 0.N работает с 0.N+1 без
  правок кода, кроме изменений, помеченных major-классом выше.
- `.d.ts`-снапшот в verify станет исполняемой защитой при CONTRACT-01: diff
  снапшота без записи класса изменения в CHANGELOG-строке коммита = красный CI.
- Deprecation: имя живёт ≥1 minor с пометкой в catalog, удаление — major.
