# Совместимость пакета

[Справка пакета](package.md) содержит версию и точки входа.
Наличие нужного выпуска проверяется в npm.

## Классы изменений

До первого подтверждённого использования в production действует ранний режим
совместимости. После подключения потребителя применяются правила правой колонки.

| Изменение | До первого production-потребителя | После |
|---|---|---|
| Новое имя иконки | minor | minor |
| Удаление или переименование имени | minor с записью об устаревании | major |
| Изменение байтов SVG с сохранением смысла | patch | patch |
| Изменение смысла или узнаваемости формы | minor | major |
| Новая ось у варианта | minor | minor |
| Удаление оси | minor | major |
| Расширение union-типа | minor | major: может сломать исчерпывающий разбор потребителя |
| Новый необязательный ключ объекта | minor | minor |
| Изменение семантики существующего ключа | Новое имя ключа | Новое имя ключа |
| Изменение внутреннего формата `topologySignature` | Непрозрачное значение, разрешено только сравнение на равенство | patch при сохранении непрозрачного контракта |
| Приёмка модели `candidate → accepted` | minor | minor |
| Изменение порогов качества | minor с обоснованием | minor с обоснованием |
| Изменение траектории или easing существующего gesture ID | Новый ID | Новый ID |
| Новая версия `proposalVersion` | Прежняя версия принимается либо получает явный отказ с кодом | То же правило |

Приёмка модели может менять геометрию в режиме по умолчанию: вместо авторского
источника возвращается принятая модель. При сохранении снимков SVG или path
фиксируйте minor-версию зависимости.

Устаревающее имя остаётся в каталоге с пометкой как минимум на один minor-выпуск.
После появления production-потребителя его удаление требует major-версии.

## Экспериментальные интерфейсы

Motion/morph-интерфейсы, включая `MotionGestureContract`, `sampleMotionGesture`,
состояния возможностей и варианты tracks, остаются экспериментальными.
В линии 0.x их union-типы могут расширяться в minor-выпуске. Обрабатывайте
неизвестный вариант. Стабилизация оформляется отдельным изменением этой политики.

`iconDesignContract.agent` описывает команды для рабочей копии репозитория.
Эти команды могут меняться вместе с инструментами разработки; установленный
пакет не предоставляет среду для их запуска.

## Проверка изменения

Сравните собранный пакет со [снимком экспортов](../release/export-surface.json).
Обновляйте снимок вместе с намеренным изменением публичных имён.
Проверка пакета также проверяет точки входа и разрешение типов у потребителя.

В ревью определите класс выпуска с учётом поведения, смысла полей,
узнаваемости формы и экспериментальных интерфейсов. Затем следуйте
[инструкции релиза](build-release.md).
