# Токенная система `system/` — отчёт о состоянии

Роль: отчёт.

Статус: в работе — слой заложен и зелёный в canonical `pnpm verify`, корпус
объявлен частично. Снимок обновляется по мере объявления семей.

## Что сделано и почему именно так

Прошлая итерация промотировала генерат в поставку без фильтра качества и
подменила чистые рисунки руки: `plus.svg` вырос с 307 до 1121 байта и получил
вырожденные сегменты `C12 5.1 12 5.1 12 5.1`. Диагноз — не «плохой генератор»,
а отсутствие трёх вещей: неприкосновенной точки отсчёта, честной меры
сходимости и запрета на выдуманное число. Все три заведены.

1. **`reference/`** — 444 оригинала, извлечённых из первого коммита каждого
   файла. Только чтение.
2. **`system/tokens.js`** — конституция. Радиусы, кромки и габариты не
   задаются, а выводятся; каждый вывод снабжён замером по корпусу.
3. **`system/check-system.js`** — расхождение больше 3% БЕЗ письменного
   аргумента = красная сборка. Входит в `pnpm verify`.

## Что выяснилось по дороге (не переоткрывать)

* **Площадная метрика на штрихах нелинейно жестока.** `1 − IoU ≈ 2δ/(2w − δ)`:
  при пере 1.8 смещение 0.027 ед. уже даёт 3%. Разброс самой руки больше: у
  `chevron-down` два терминала одного штриха стоят на 0.063 друг от друга.
  Поэтому введена вторая мера — смещение контура, и вердикт `registration`
  (медиана ≤ 0.06 ед. при сопоставимой площади) считается сходимостью.

* **Габарит держат ЧЕРНИЛА, а не скелет** — но не везде одинаково.
  У шеврона при смене пера Outline→Filled рука сохранила чернила (±6.96) и
  поджала скелет (6.11 → 5.71). Учёт этого снял у Filled-шевронов 39%
  отклонения. У стрелки закреплены РАЗНЫЕ вещи: осевые терминалы (вершина и
  хвост) — по чернилам, а диагональный раствор головы — по скелету
  (5.74 ↔ 5.71 при разных перьях). Проверяй это на каждой новой семье.

* **Сглаживание угла ζ = 0.6 подтвердилось независимо.** Реализация через
  кубику с нулевой кривизной у прямой (G2) воспроизводит скруглённый квадрат
  Filled с отклонением 0.05%.

* **Слияние узлов на выводе обязательно.** Конструктор порождает разрезанный
  вершиной многоугольника терминал; без слияния `plus` получает 21 команду
  вместо 14. Реализовано в `core/path.js`, модель не трогает.

* **Класс важнее иконки.** Двадцать имён семьи «в круге» объявлены одним
  классом и двадцатью начинками; 40 вариантов из 40 сошлись. Ищи класс раньше,
  чем рисуешь второй похожий глиф.

## Что осталось

* Объявлены не все 222 имени. Текущее состояние показывает
  `node system/build.js`; полная картина — `docs/preview.html`.
* `system/promote.js` ни разу не запускался с `--write`. Промоушен осмыслен
  только когда корпус объявлен целиком: иначе `svg/` окажется наполовину
  рукой, наполовину системой, без единого прочтения. Фильтры готовы
  (сходимость + непревышение сложности), решение за владельцем.
* Анимации сознательно не делались. Конструкция к ним подготовлена: дуга
  хранит центр (ось вращения), обводка хранит скелет (траектория draw), оси
  вариативности уже параметризуют то, что будет двигаться (луч солнца, хвост
  стрелки, вес).

## Как продолжать

```bash
node system/check-family.mjs system/glyphs/<семья>.js   # мерить свою семью
node system/build.js                                    # общий отчёт
node system/preview.js                                  # страница сходимости
node system/promote.js                                  # что готово к поставке
```

Контракт для автора семьи — [docs/system.md](../docs/system.md). Порядок
работы жёсткий: подогнать фиттером → увидеть закон → подставить закон →
измерить цену подстановки. Подогнанные числа в декларацию не попадают.
