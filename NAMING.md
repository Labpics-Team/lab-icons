# Имена Lab Icons — справка

## Идентификатор и производные имена

Имя глифа — kebab-case ID, например `alert-circle`. Исходные имена берутся
из `svg/Outline/`; парность вариантов проверяется отдельно, а производный
каталог не редактируется как второй независимый список.

| Представление | Форма | Пример |
|---|---|---|
| ID | kebab-case | `alert-circle` |
| Outline-файл | `svg/Outline/<id>.svg` | `svg/Outline/alert-circle.svg` |
| Filled-файл | `svg/Filled/<id>_filled.svg` | `svg/Filled/alert-circle_filled.svg` |
| Статический экспорт | lowerCamel ID + вариант | `alertCircleOutline`, `alertCircleFilled` |
| Тип | PascalCase | `IconName` |
| Ключ декларации анатомии | Исходный ID | `alert-circle` |

Трансформацию статических имён выполняет [сборка](scripts/build.js).
Текущую поверхность контролирует [снимок экспортов](release/export-surface.json).
Имена в машинном контракте не переводятся вместе с поясняющим текстом.

## Совместимость путей

Различие суффиксов Outline и Filled является существующим файловым
контрактом. Его не исправляют ради симметрии: переименование требует
учёта потребителей и [классификации совместимости](docs/semver-policy.md).
Выводимость имени из ID важнее одинакового внешнего написания путей.

## Цвет

Публичные SVG наследуют `currentColor`. Проверка `check:colors` контролирует
поставляемую цветовую поверхность; README не должен обещать фиксированную
заливку вместо наследования. Документационная проверка этого утверждения
не заменяет проверку самих SVG.

## Рабочие записи

Завершённые сессионные инструкции не входят в действующую документацию.
Открытая работа координируется в Issues и PR. Воспроизводимые исследования
с входами, методом и результатом сохраняются как доказательные артефакты,
а не выдаются за текущий статус библиотеки.
